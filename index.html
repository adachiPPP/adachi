kyon linux overview

kyon linux is an independent arch based custom distribution created with care featuring the custom nya package manager init options and a beautiful lightweight user experience check out the official repository and downloads to try it out

heres the website :3

nya package manager

nya package manager is here to completely replace yay and pacman from the root. pacman was never complete from my perspective, and needing an aur helper just to get packages from aur seemed pointless... so i just made my own! nya comes with a TON of features and its still lighter than pacman :3

nya supports pacman repos, arch user repository, its own recipe thingy called nya-hosts, nix and last but not least flatpak. its job is to combine everything in one package manager and its pretty easy to use too!
